Frequently asked questions

Answers about supported links and media availability.

Why does the tool show video details but no download?

Video metadata and a downloadable media file are separate things. The connected backend currently retrieves metadata and offers downloads for files uploaded by an authorized owner. If no file is linked to that video ID, the download option stays unavailable.

Which YouTube URLs can I check?

The backend accepts standard YouTube watch links, Shorts links, live links, embed links, and youtu.be links when they contain a valid video ID.

Will this always show 1080p or 4K options?

No. The page only displays formats that the configured backend actually supplies. It does not invent resolution choices or file sizes.

Can I download any video from YouTube?

Only use downloads you own or are authorized to access. YouTube metadata access does not itself grant permission to download a video's media stream. This interface does not bypass platform restrictions.
